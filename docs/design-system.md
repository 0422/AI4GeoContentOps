# AI4GeoContentOps 设计系统

> 2026-10-23：建立供后续页面开发复用的视觉与交互约束。当前主题以浅色为主，保留未来深色主题的语义化扩展空间。

## 产品与视觉方向

本产品是内容生产工作台。内容生成是主工作区；品牌库、样本库、内容策略提供事实和规则；设置维护分类与模型。设计采用 Modern Editorial SaaS：内容优先、层级清楚、操作紧凑、色彩克制。参考成熟企业软件的组织方式，不复制具体页面。

不使用装饰性 AI 图标、大面积渐变、霓虹、玻璃拟态、无意义统计卡、过度阴影或层层嵌套的大圆角卡片。

## 主题 Token

实际值集中定义于 [design-tokens.css](../frontend/src/design-tokens.css)。页面样式优先引用语义变量，不在组件中另起一套主题色。

| 用途 | Token | 当前值 |
|---|---|---|
| 页面背景 | `--color-canvas` | `#F8F9FA` |
| 内容表面 | `--color-surface` | `#FFFFFF` |
| 主文字 | `--color-text` | `#17191D` |
| 次文字 | `--color-text-secondary` | `#5F6670` |
| 弱文字 | `--color-text-muted` | `#626872` |
| 边界 | `--color-border` | `#E5E7EB` |
| 主要操作与焦点 | `--color-accent` | `#345C50` |
| 成功、警告、错误 | `--color-success / warning / danger` | 仅表达真实状态 |

间距以 4px 为基础，常用 8、12、16、24、32px。控件圆角 6px，面板圆角 10px。默认无面板阴影；仅未来的浮层可使用 `--shadow-menu`。动效使用 `--motion-fast`（150ms），并尊重减少动效的系统设置。

## 排版与布局

- 字体：Inter 加中文系统字体。正文 14px，辅助 12–13px，页面标题约 24–25px。
- 侧边栏已标明模块时，内容区直接展示当前操作。模块 H1 保留给读屏器，不在页面左上角重复显示；可见的板块 H2 说明当前任务。
- 桌面导航保持稳定；笔记本宽度下表单与侧栏转换为单列；窄屏保留可横向滚动的导航及完整可操作按钮。
- 用边框、字重和留白区分层级。资料列表以行分隔，表单和文章正文保留充足阅读宽度。

## 控件与状态

| 控件 | 规则 |
|---|---|
| 主按钮 | 每个操作区通常只有一个；用于“生成”“保存”“发布”等确认动作。 |
| 次按钮 | 用于查看、展开、复制、添加；危险操作使用明确的危险色与确认。 |
| 输入框与选择框 | 高度约 40px，标签常驻，焦点有可见边框与焦点环；错误紧邻出错区域。 |
| 列表与标签 | 列表先展示名称、状态及少量可比较元数据；状态色只代表真实状态。 |
| 空状态 | 解释当前缺少什么，并给出可执行的下一步。 |
| 加载与保存 | 按钮显示进行中且暂不可重复提交；成功、失败反馈靠近触发位置。 |
| 说明信息 | 常态说明优先写进标签、选项或占位示例；长规则用 `details` 按需展开。权限确认、取文失败、截断和保存失败等信息必须可见。 |

交互须保留键盘焦点、原生表单标签和必要的 `aria` 状态。新页面不要依赖纯颜色表达状态。

## 页面规则

1. **内容生成**：创作简报是主操作；策略预览只先给匹配结论，完整规则按需展开。最近任务有直达稿件入口；文章阅读与编辑优先。
2. **样本库**：先发现或浏览内容，再按需展开长录入表单。候选与已保存样本必须区分；摘要和正文必须区分。取文失败时保留可手动补录的路径。
3. **内容策略**：依次选择适用范围和样本、查看版本、编辑规则。删除入口靠近版本列表；参考来源按需展开。
4. **品牌库**：列表突出名称、版本、启用状态；编辑区突出介绍和可核对来源。事实未审核时不进入生成。
5. **设置**：以内容选项和模型配置分组；仅显示决定操作所需的说明。

## 实施边界

现有前端是 React、TypeScript、Vite 与手写 CSS。主题文件通过 `main.tsx` 导入，`workspace-modern.css` 覆盖旧样式。旧样式保留供本轮对照，未来清理时再经单独审核。新增页面应直接复用 Token，避免继续给旧文件追加硬编码颜色。

本轮不修改 API、数据库、任务状态、路由或后端。视觉验收应检查五个页面的桌面、笔记本与窄屏布局，重点核对表单提交、候选预填、策略版本操作、品牌启用和稿件保存。
